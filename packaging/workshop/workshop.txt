title=Talky - LibertyTalk Live Events
description=Talky connects your stream to your Project Zomboid game. When LibertyTalk receives a follow, a sub, bits, a raid, a channel point redemption or a Super Chat, it calls the Talky bridge running on your PC, and the mod plays the matching workflow in your game: a zombie named after the new follower, a horde sized by the raid, the helicopter for 1000 bits, a storm, an item for a donation.
description=
description=[h2]What you need[/h2]
description=[list]
description=[*]Project Zomboid Build 42.20.1 or later: single player, hosted game or dedicated server
description=[*]On the streamer's PC: Windows 10 or 11 with Node.js 18 or later
description=[*]The Talky bridge, from the GitHub releases: https://github.com/Tech-Liberty/talky-project-zomboid/releases
description=[*]cloudflared, which gives the bridge a public HTTPS address
description=[*]A LibertyTalk account with Twitch or YouTube connected, and the "Project Zomboid · Talky" widget
description=[/list]
description=
description=[h2]How it works[/h2]
description=Project Zomboid mods cannot open network connections. The bridge receives the webhooks from LibertyTalk and writes jobs to Zomboid/Lua, and the mod reads them every second. Press F8 in game to open the Talky window: bridge status, webhooks, workflows, game events and settings.
description=This Workshop item contains the mod only. Download the bridge zip from GitHub, extract it to a folder you keep (for example Documents/Talky, not Zomboid/mods) and double-click start-bridge.cmd: on its first start, the bridge creates its configuration and copies its token to the clipboard. Do not copy the Talky folder of the zip to Zomboid/mods: the game would see two mods with the id Talky.
description=
description=[h2]Multiplayer[/h2]
description=Talky must be on the server and on every client. Dedicated server: add Talky to Mods= and the id of this item to WorkshopItems= in the server .ini. Hosted game: add Talky on the Mods and Steam Workshop pages of Host > Manage settings. The bridge stays on the streamer's PC: nothing else runs on the server machine.
description=The server runs the effects, so every player sees them, and applies its own limits on the Talky page of the sandbox options: who may use Talky, zombies per action and per 10 minutes, one switch per category, cooldowns, distance from other players. By default admins and moderators may use Talky; list other players in Allowed players. In a hosted game the host is not admin at first: press "Allow me (host)" on the F8 Status page. Fire and the helicopter are off by default on a server.
description=
description=[h2]Limits[/h2]
description=The address of a quick Cloudflare tunnel changes at each launch: paste the new one in the widget settings on LibertyTalk. Update the mod and the bridge together: game events and Test now need bridge 0.4.0. Version 0.4.0 was tested against a simulated game API (single player, dedicated server, hosted game); please report on GitHub anything that does not work in a real game.
description=

description=[h2]Fonctionnement[/h2]
description=Les mods de Project Zomboid ne peuvent pas ouvrir de connexion réseau. Le bridge reçoit les webhooks de LibertyTalk et écrit des jobs dans Zomboid/Lua, que le mod lit chaque seconde. Appuyez sur F8 en jeu pour ouvrir la fenêtre Talky : état du bridge, webhooks, workflows, événements du jeu et réglages.
description=Cet élément du Workshop contient uniquement le mod. Téléchargez le zip du bridge sur GitHub, décompressez-le dans un dossier que vous gardez (par exemple Documents/Talky, pas dans Zomboid/mods) et double-cliquez sur start-bridge.cmd : au premier lancement, le bridge crée sa configuration et copie son jeton dans le presse-papiers. Ne copiez pas le dossier Talky du zip dans Zomboid/mods : le jeu verrait deux mods avec l'id Talky.
description=
description=[h2]Multijoueur[/h2]
description=Talky doit être sur le serveur et sur chaque client. Serveur dédié : ajoutez Talky à Mods= et l'id de cet élément à WorkshopItems= dans le .ini du serveur. Partie hébergée : ajoutez Talky sur les pages Mods et Workshop Steam de Héberger > Modifier les réglages. Le bridge reste sur le PC du streamer : rien d'autre ne tourne sur la machine du serveur.
description=Le serveur exécute les effets, tous les joueurs les voient, et il applique ses propres limites sur la page Talky des options bac à sable : qui peut utiliser Talky, zombies par action et par 10 minutes, un interrupteur par catégorie, délais, distance des autres joueurs. Par défaut, les admins et modérateurs peuvent utiliser Talky ; listez les autres joueurs dans Joueurs autorisés. En partie hébergée, l'hôte n'est pas admin au départ : cliquez sur « M'autoriser (hôte) » sur la page Statut de F8. Le feu et l'hélicoptère sont désactivés par défaut sur un serveur.
description=
description=[h2]Limites[/h2]
description=L'adresse d'un tunnel Cloudflare rapide change à chaque lancement : collez la nouvelle dans les réglages du widget sur LibertyTalk. Mettez à jour le mod et le bridge ensemble : les événements du jeu et Tester maintenant demandent le bridge 0.4.0. La version 0.4.0 a été testée sur une API du jeu simulée (solo, serveur dédié, partie hébergée) ; signalez sur GitHub ce qui ne fonctionne pas en partie réelle.
